# Story 1.8: Web App Foundation & Authentication UI

## Status
Done

## Story
**As a** user,
**I want** a functional web application with login/register pages,
**so that** I can create an account and log in from my browser.

## Acceptance Criteria
1. React 18+ application scaffolded with TypeScript, React Router v6, and Tailwind CSS
2. Login page created at /login with email and password inputs, "Sign in" button, and OAuth buttons (Google, Apple)
3. Registration page created at /register with email, password, firstName inputs and "Create account" button
4. Form validation implemented using React Hook Form + Zod (client-side validation mirrors backend rules)
5. Authentication state managed using Zustand store (token storage, user profile)
6. Protected route wrapper created, redirecting unauthenticated users to /login
7. JWT tokens stored in memory (access) and httpOnly cookie (refresh), automatic refresh on 401 responses
8. Loading states and error messages displayed for all auth actions (login, register, OAuth)

### Authentication State Management
**Zustand Store Structure:**
```typescript
interface AuthState {
  user: User | null;
  accessToken: string | null;
  isAuthenticated: boolean;
  isLoading: boolean;
  error: string | null;

  login: (email: string, password: string) => Promise<void>;
  register: (email: string, password: string, firstName: string) => Promise<void>;
  logout: () => Promise<void>;
  refreshAccessToken: () => Promise<void>;
  setAccessToken: (token: string) => void;
  clearAuth: () => void;
}
```

**Token Storage:** [Source: [security-and-performance.md](../architecture/security-and-performance.md#authentication-security)]
- **Access Token:** Stored in memory only (authStore state, NOT localStorage)
- **Refresh Token:** Stored in httpOnly cookie (set by backend, inaccessible to JavaScript)
- **Rationale:** Prevents XSS attacks (JavaScript can't access tokens)

**Persistence:**
- DO NOT persist tokens (security risk)
- Optionally persist user profile (without tokens) using zustand persist middleware
- On page refresh, check if httpOnly cookie exists → attempt token refresh
- If refresh fails, user must log in again

[Source: [security-and-performance.md](../architecture/security-and-performance.md#frontend-security)]

### API Client Configuration
**Axios Instance Setup:**
```typescript
// src/services/apiClient.ts
import axios from 'axios';
import { authStore } from '../stores/authStore';

const apiClient = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || 'http://localhost:3001',
  withCredentials: true, // Send httpOnly cookies
  headers: {
    'Content-Type': 'application/json',
  },
});

// Request interceptor: Add auth token
apiClient.interceptors.request.use((config) => {
  const token = authStore.getState().accessToken;
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// Response interceptor: Handle 401 and refresh token
apiClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;

    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;

      try {
        await authStore.getState().refreshAccessToken();
        const newToken = authStore.getState().accessToken;
        originalRequest.headers.Authorization = `Bearer ${newToken}`;
        return apiClient(originalRequest);
      } catch (refreshError) {
        authStore.getState().clearAuth();
        window.location.href = '/login';
        return Promise.reject(refreshError);
      }
    }

    return Promise.reject(error);
  }
);

export default apiClient;
```

### Form Validation Rules

```typescript
// src/schemas/authSchemas.ts
import { z } from 'zod';

export const registerSchema = z.object({
  email: z.string().email('Invalid email format'),
  password: z
    .string()
    .min(8, 'Password must be at least 8 characters')
    .regex(/[A-Z]/, 'Password must contain at least 1 uppercase letter')
```

**Client-Side Validation:**
- Matches backend validation rules exactly
- Provides immediate feedback (better UX)
- Does NOT replace server-side validation (defense in depth)

### OAuth Integration Flow
**Frontend OAuth Flow:** [Source: [1.6.oauth-authentication.md](1.6.oauth-authentication.md)]
```
1. User clicks "Sign in with Google" button
   ↓
2. Frontend redirects to: GET ${API_BASE_URL}/api/auth/google
   ↓
3. Backend redirects to Google authorization page
   ↓
4. User authorizes on Google
   ↓
5. Google redirects to: GET /api/auth/google/callback?code=<auth_code>
   ↓
6. Backend processes OAuth, generates JWT tokens
   ↓
7. Backend redirects to: https://app.bmadrecette.com/auth/success?token=<accessToken>
   Set-Cookie: refreshToken=...
   ↓
8. Frontend (AuthSuccessPage):
   - Extract token from URL query param
   - Store in authStore.setAccessToken(token)
   - Fetch user profile
   - Remove token from URL (security)
   - Redirect to /recipes
```

**Security Consideration:**
- Token in URL is temporary (only during redirect)
- Immediately remove from URL after extraction
- Use window.history.replaceState() to remove from browser history

### Error Handling
**Authentication Errors:**

1. **Registration Errors:**
   - 409 Conflict (duplicate email): "Email already registered. Please sign in instead."
   - 400 Bad Request (validation error): Display specific field errors
   - Network error: "Unable to connect. Please check your connection."

2. **Login Errors:**
   - 401 Unauthorized: "Invalid email or password" (generic, no user enumeration)
   - 429 Too Many Requests: "Too many login attempts. Please try again in 10 minutes."
   - Network error: "Unable to connect. Please check your connection."

3. **OAuth Errors:**
   - Missing token in callback: "Authentication failed. Please try again."
   - OAuth provider error: Extract error param from URL `?error=access_denied`
   - Backend error: "Authentication failed. Please try signing in with email/password."

**Error Display:**
- Inline field errors: Red text under input field
- Form-level errors: Red alert box above form with icon
- Clear error messages with actionable guidance

### Security Considerations
**Frontend Security:** [Source: [security-and-performance.md](../architecture/security-and-performance.md#frontend-security)]
- **XSS Prevention:** React's built-in escaping, DOMPurify for user content (not needed in auth forms)
- **Token Storage:** Access token in memory only, refresh token in httpOnly cookie (set by backend)
- **HTTPS Only:** Production app served over HTTPS (Vercel default)
- **No Sensitive Data in localStorage:** Never store tokens or passwords in localStorage/sessionStorage
- **CSP Headers:** Content Security Policy headers set by backend/Vercel

**Authentication Security:**
- Password input type="password" (masked)
- Generic error messages (no user enumeration: "Invalid credentials" not "Email not found")
- Logout clears all auth state
- Token refresh happens automatically on 401 (transparent to user)

**Zustand Auth Store:**
```typescript
// src/stores/authStore.ts
import { create } from 'zustand';
import { persist } from 'zustand/middleware';
import * as authService from '../services/authService';

interface User {
  id: string;
  email: string;
  firstName: string;
}

interface AuthState {
  user: User | null;
  accessToken: string | null;
  isAuthenticated: boolean;
  isLoading: boolean;
  error: string | null;

  login: (email: string, password: string) => Promise<void>;
  register: (email: string, password: string, firstName: string) => Promise<void>;
  logout: () => Promise<void>;
  refreshAccessToken: () => Promise<void>;
  setAccessToken: (token: string) => void;
  clearAuth: () => void;
}

export const useAuthStore = create<AuthState>()(
  persist(
    (set, get) => ({
      user: null,
      accessToken: null,
      isAuthenticated: false,
      isLoading: false,
      error: null,

      login: async (email, password) => {
        set({ isLoading: true, error: null });
        try {
          const { user, accessToken } = await authService.login(email, password);
          set({ user, accessToken, isAuthenticated: true, isLoading: false });
        } catch (error: any) {
          set({ error: error.message, isLoading: false });
          throw error;
        }
      },

      register: async (email, password, firstName) => {
        set({ isLoading: true, error: null });
        try {
          const { user, accessToken } = await authService.register(email, password, firstName);
          set({ user, accessToken, isAuthenticated: true, isLoading: false });
        } catch (error: any) {
          set({ error: error.message, isLoading: false });
          throw error;
        }
      },

      logout: async () => {
        try {
          await authService.logout();
        } finally {
          set({ user: null, accessToken: null, isAuthenticated: false });
        }
      },

      refreshAccessToken: async () => {
        const { accessToken } = await authService.refreshAccessToken();
        set({ accessToken });
      },

      setAccessToken: (token: string) => {
        set({ accessToken, isAuthenticated: true });
      },

      clearAuth: () => {
        set({ user: null, accessToken: null, isAuthenticated: false, error: null });
      },
    }),
    {
      name: 'auth-storage',
      partialize: (state) => ({ user: state.user }), // Only persist user, NOT tokens
    }
  )
);
```

```typescript
import { Navigate, useLocation } from 'react-router-dom';
import { useAuthStore } from '../stores/authStore';

export function ProtectedRoute({ children }: { children: React.ReactNode }) {
  const isAuthenticated = useAuthStore((state) => state.isAuthenticated);
  const location = useLocation();
```

```typescript
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

      // Error handled by store
    }

      {errors.email && <span>{errors.email.message}</span>}

      {error && <div className="error">{error}</div>}

      <button type="submit" disabled={isLoading}>
        {isLoading ? 'Signing in...' : 'Sign in'}
      </button>

      <a href={`${import.meta.env.VITE_API_BASE_URL}/api/auth/google`}>

      </a>
    </form>
```
