# Story 8.3: UI Revamp - Onboarding, Accessibility, Performance

## Status
Approved

## Story
**As a** new or returning user,
**I want** an accessible and fast onboarding and core experience,
**so that** I can get started quickly and confidently.

## Acceptance Criteria

1. Onboarding flow matches the spec (welcome, goal selection, first recipe entry/scan/skip, feature tour) and is completable in <= 5 minutes
2. Accessibility meets WCAG 2.1 AA requirements defined in the spec (contrast, focus indicators, keyboard navigation, ARIA labeling)
3. Reduced motion preferences are respected per spec (disable decorative animations)
4. Performance targets from the spec are met on key pages (FCP < 1.5s, TTI < 3s)
5. Offline resilience indicators and sync status affordances appear where specified in the spec
6. Onboarding entry is wired from existing auth flow without breaking `/register` or `/login` behavior
