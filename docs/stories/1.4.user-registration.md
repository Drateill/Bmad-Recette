# Story 1.4: User Registration with Email/Password

## Status
✅ Completed - 2026-01-07

## Story
**As a** new user,
**I want** to create an account using my email and password,
**so that** I can access the BMad Recette platform and save my data.

## Acceptance Criteria
1. POST /api/auth/register endpoint created accepting {email, password, firstName} with validation
2. Email validation enforces valid format; password validation enforces minimum 8 characters, 1 uppercase, 1 number
3. Password hashing implemented using bcrypt before storage (never store plaintext)
4. User record created in PostgreSQL users table with unique email constraint
5. Registration returns 201 Created with user object (excluding password) and JWT access + refresh tokens
6. Duplicate email registration returns 409 Conflict with clear error message
7. Rate limiting applied: max 5 registration attempts per IP per hour

### API Specification

**Endpoint:** POST /api/auth/register

**Request Body:**
```typescript
{
  email: string;      // Valid email format
  password: string;   // Min 8 chars, 1 uppercase, 1 number
  firstName: string;  // User's first name
```

**Success Response (201 Created):**
```typescript
{
  user: {
    id: string;
    email: string;
    firstName: string;
    createdAt: string;  // ISO 8601 timestamp
  };
  accessToken: string;   // JWT, expires in 15 minutes
  refreshToken: string;  // JWT, expires in 7 days
```

**Error Responses:**
- 400 Bad Request: Invalid email format or weak password
- 409 Conflict: Email already registered
- 429 Too Many Requests: Rate limit exceeded (5 attempts/hour)

### JWT Token Configuration

**Access Token:**
- Expiration: 15 minutes
- Payload: `{ sub: userId, email: string, type: 'access' }`
- Used for: API authentication via Bearer token in Authorization header

**Refresh Token:**
- Expiration: 7 days
- Payload: `{ sub: userId, type: 'refresh' }`
- Stored: Redis with key `refresh_token:${userId}` and TTL matching expiration
- Used for: Renewing access token (Story 1.7)

**JWT Secret:**
- Access via ConfigService: `configService.get('jwt.secret')`
- Never hardcode or access via process.env directly

### Password Security Requirements

**Hashing:**
- Algorithm: bcrypt
- Salt rounds: 10
- Never store plaintext passwords
- Hash before any database operation

**Validation Rules:**
- Minimum 8 characters
- At least 1 uppercase letter (A-Z)
- At least 1 number (0-9)
- Use regex: `/^(?=.*[A-Z])(?=.*\d).{8,}$/`

**Implementation:**
```typescript
import * as bcrypt from 'bcrypt';

async function hashPassword(plainText: string): Promise<string> {
  const saltRounds = 10;
  return await bcrypt.hash(plainText, saltRounds);
}

async function comparePassword(plainText: string, hash: string): Promise<boolean> {
  return await bcrypt.compare(plainText, hash);
}
```

**Integration Test Example (register.e2e-spec.ts):**
```typescript
describe('POST /api/auth/register (e2e)', () => {
  it('should register user successfully', () => {
    return request(app.getHttpServer())
      .post('/api/auth/register')
      .send({ email: 'newuser@example.com', password: 'Test1234', firstName: 'Jane' })
      .expect(201)
      .expect((res) => {
        expect(res.body.user.email).toBe('newuser@example.com');
        expect(res.body.user.passwordHash).toBeUndefined(); // Never expose hash
        expect(res.body.accessToken).toBeDefined();
        expect(res.body.refreshToken).toBeDefined();
      });
  });

  it('should return 409 for duplicate email', async () => {
    // First registration
    await request(app.getHttpServer())
      .post('/api/auth/register')
      .send({ email: 'duplicate@example.com', password: 'Test1234', firstName: 'John' });

    // Duplicate attempt
    return request(app.getHttpServer())
      .post('/api/auth/register')
      .send({ email: 'duplicate@example.com', password: 'Test1234', firstName: 'John' })
      .expect(409)
      .expect((res) => {
        expect(res.body.error.code).toBe('EMAIL_ALREADY_EXISTS');
      });
  });

  it('should enforce rate limiting', async () => {
    const payload = { email: 'rate@example.com', password: 'Test1234', firstName: 'John' };

    // Make 5 requests (should succeed)
    for (let i = 0; i < 5; i++) {
      await request(app.getHttpServer())
        .post('/api/auth/register')
        .send({ ...payload, email: `rate${i}@example.com` })
        .expect(201);
    }

    // 6th request should fail with 429
    return request(app.getHttpServer())
      .post('/api/auth/register')
      .send({ ...payload, email: 'rate6@example.com' })
      .expect(429);
  });
});
```
